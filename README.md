# Wells Farm Mini — Sylva Style

실행 방법:

```bash
npm install
npm run dev
```

브라우저에서 터미널에 뜨는 localhost 주소를 열면 됩니다.
Chrome 개발자도구에서 390px 모바일 폭으로 보면 가장 정확합니다.

## 메인 화면

`/wells/#/`에서 소개 → 제품 선택 → 3D 구조 → 사용 방법 → 채소 선택 → 고객센터를
한 페이지에서 아래로 스크롤하며 볼 수 있습니다. 메뉴와 제품 구조 버튼은 해당 영역으로 이동합니다.
이전에 분리했던 `/products`, `/inside`, `/structure`, `/how-it-works`, `/seed` 주소도
메인 화면의 해당 영역으로 연결됩니다. 고객센터(`/support`), 로그인과 팜이 상담은 별도 화면으로 유지됩니다.
기기 설정 팝업을 닫아도 현재 위치와 기기 설정은 유지됩니다.

## 로그인과 팜이 상담 체험

- `/wells/#/ai` — 팜이 대화 시작 화면
- `/wells/#/chat` — 주제 선택, 미니팜 상태, 물 보충 안내와 완료 체험
- `/wells/#/login` — 로그인, 이메일 형식 오류와 비밀번호 오류
- `/wells/#/login/complete` — 체험 로그인 완료
- `/wells/#/register` — 샘플 미니팜 이름과 채소 등록

로그인 화면의 **체험 계정 채우기**를 누른 뒤 로그인하면 완료 화면으로 이동합니다.
이메일·비밀번호는 서버에 전송하거나 브라우저 저장소에 저장하지 않습니다.
현재 탭의 체험 로그인 여부만 `sessionStorage`에 보관하며 로그아웃하면 삭제합니다.
간편 로그인·회원가입·비밀번호 변경은 안내 화면이며 실제 인증 서비스와 연결되지 않습니다.

기본 체험 모드의 팜이 상담은 정해진 안내와 체험 상태를 표시합니다.
실제 AI 대화는 [연결 안내](docs/fami-ai-setup.md)에 따라 Cloudflare Workers AI를 연결하면 사용할 수 있습니다.
기본 연결 방식에는 별도의 AI API 키가 필요하지 않으며 Cloudflare 계정이 필요합니다.
AI 모드에서는 질문·최근 대화·체험 기기 정보가 모델 서비스로 전송됩니다.
연결이 실패하면 정해진 답변으로 대체하지 않고 오류와 재시도 버튼을 표시합니다.
물 보충 완료는 체험 상태만 갱신합니다. 스마트 제어는 기존 기기 설정 팝업을 사용합니다.
대화는 현재 화면 세션의 메모리에만 유지되며, 전체 새로고침 시 초기화됩니다.
화면 속 회색 키보드 모형 대신 휴대폰의 실제 키보드를 사용합니다.


## 고객센터와 버튼 동작

- `/wells/#/support` — 첨부 디자인의 고객센터. 전화 상담은 전화 앱, 상담톡은 팜이 대화, 하단 카드는 팜이 소개로 연결됩니다.
- `/wells/#/support/faq` — 질문 검색, 분류 선택, 답변 펼치기와 관련 화면 바로가기.
- `/wells/#/support/inquiries` — 문의 작성·내역 펼치기·삭제 확인과 취소. 최대 20개를 현재 탭의 `sessionStorage`에 보관합니다. 실제 고객센터로 접수하거나 답변을 생성하지 않습니다. 개인정보를 입력하지 마세요. 저장소 이용 실패 시 화면 보관만 가능하다고 표시합니다.
- 로그인 오류는 해당 입력란으로 포커스를 옮깁니다. 간편 로그인 버튼은 제공자 연결 전임을 알리고 체험 계정으로 계속할 수 있게 합니다.
- 상담 상태 카드는 생성 당시 이름·채소·온도·조명을 보존합니다. 이후 설정을 바꿔도 과거 기록이 바뀌지 않습니다. 물 보충 가이드의 완료 버튼은 한 번 처리한 뒤 비활성화됩니다.
- 3D 모델은 스크롤·분해 슬라이더·시점 선택·드래그·방향키·화면 확대/축소 버튼·조립 초기화를 지원합니다. 동작 줄이기 설정에서는 분해 전환을 즉시 적용합니다.

## 브라우저 회귀 검증

별도 터미널에서 개발 서버를 실행하고, 독립 Chromium 프로필을 사용합니다. 테스트는 해당 탭의 체험 문의 내역을 초기화하므로 일반 브라우저 프로필을 사용하지 마세요.

```sh
chromium --headless --no-sandbox --disable-dev-shm-usage --enable-unsafe-swiftshader --use-angle=swiftshader --no-proxy-server --remote-debugging-port=9222 --user-data-dir=/tmp/wells-ui-test about:blank
# 다른 터미널 (Node.js 24)
node tests/ui-smoke.mjs
```

`CDP_URL`은 Chromium 디버깅 주소, `APP_URL`은 앱 기본 주소(마지막 `/` 포함), `PREVIEW_DIR`은 캡처 경로를 지정합니다. 기본 캡처 위치는 `/tmp/wells-ui-previews`입니다. 테스트는 FAQ, 문의 저장·새로고침·삭제, 로그인 오류와 완료, 모든 스마트 제어 탭, 잠금, 상담 상태 기록, 물 보충, 복사, 작은 뷰포트의 입력창, 모바일/데스크톱 가로 넘침, WebGL 3D 분해·시점·확대/축소·키보드·재조립을 검증합니다. 실제 AI 모델 응답과 외부 인증은 별도 서비스 연결이 필요합니다.
